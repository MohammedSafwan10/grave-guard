## 0. How to use this file

> **Where files go:** save originals to `assets-src/art/<folder>/` (images) and `assets-src/music/` (music), then run `python tools/build_art.py` / `python tools/build_audio.py`. The game loads the built files from `public/assets/`.

1. Save the concept image as `docs/concept/concept_main.png`. It is the style reference for everything.
2. Open **one new ChatGPT chat** for all images, so the style stays consistent.
3. Send the **Style Lock** message (section 1) first, with `concept_main.png` attached.
4. Send each asset prompt **one at a time**. One image per message.
5. Download each result as **PNG** and save it with the **exact file name and folder** given. Names are lowercase with underscores. The game code loads these names.
6. If an image comes out wrong, reply in the same chat: *"Same object, but fix: ..."*. Don't start a new chat.
7. Log each finished asset in the table in `CREDITS.md` (tool + date). The Devpost write-up needs it.

**Priority:** do all **P1** assets first. The game can ship with only P1. **P2** adds polish.

**Sizes ChatGPT supports:** square `1024Ã—1024`, landscape `1536Ã—1024`, portrait `1024Ã—1536`. Don't ask for others.

**If transparency fails** (you get a white or checkerboard *drawn* background): ask again with
*"Regenerate with a real transparent PNG background."* If it still fails, ask for a **flat solid magenta (#FF00FF) background** and save it anyway. I will remove the magenta with a script.

**Rules that keep us safe**
- Never mention other games, studios, films or artists in prompts (no "PvZ style", no artist names).
- No text, letters or numbers inside images. The code draws all text so it stays sharp and editable.
