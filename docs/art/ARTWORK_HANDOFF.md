## Integration notes

- Read ARTWORK_QA.json for actual dimensions, mode, byte count and visible alpha bounds.
  Prompt dimensions are not guaranteed: do not assume every square is 1024px.
- Preserve aspect ratios. Size units by visible alpha bounds rather than canvas size.
- Grounded defenders and Bone Knight use a bottom-center anchor derived from visible
  bounds. Offset floating enemies above lanes with gentle idle motion.
- Keep the camera fixed to suit the painted three-quarter views.
- Render quiz questions, answers, prices, health and streak labels as editable HTML/CSS.
  The logo is the only intentionally text-bearing image.
- ui_spellbook.png is blank parchment. Keep text and answers inside the usable interior,
  below the crescent charm. Test long questions and four actual interactive buttons.
- ui_shop_card.png contains blank portrait space and price plate; compose unit art and
  text on top. Match the selected shop card to the placement preview.
- bg_sky is opaque. Layer bg_far_hills and fg_gate_left over it using their alpha.
  Their soft glows cover a broad region; check compositing against actual scenery.
- tex_tile_stone is for individual tiles; its painted bevel is not a normal map.
  Texture wrap seams need runtime inspection; seamless tiling is not certified.
- Source PNGs total about 39 MB. Preserve originals; produce optimized runtime
  derivatives and load only needed scene assets. Avoid preloading every source image.
  Recheck soft alpha edges against both light and dark backgrounds after optimization.
- Static poses support bob/recoil/glow, not genuine walk cycles or skeletal animations.
  These painted sprites do not dynamically relight like meshes.
